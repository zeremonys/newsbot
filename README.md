# News Trader

บอทอ่านข่าวแล้วบอกว่าหุ้นตัวไหนน่าจะขึ้นหรือลง ส่งเข้า Discord ทุกชั่วโมง

ทุกรอบบอทจะดึงข่าวจากเว็บข่าวประมาณ 28 แห่งทั่วโลก ส่งหัวข่าวให้ Gemini เลือกข่าวที่น่าจะมีผลกับราคาหุ้นจริง ๆ แล้วโพสต์ลง Discord ว่าหุ้นตัวไหนควรขึ้น (LONG) หรือควรลง (SHORT) จากนั้นบอทจะจดราคาไว้ พอครบกำหนดก็กลับมาเช็กว่าทายถูกหรือผิด และเทียบกับดัชนีตลาดในช่วงเดียวกัน

ทั้งหมดรันบน GitHub Actions ไม่ต้องเปิดคอมทิ้งไว้ และไม่มีค่าใช้จ่าย

สัญญาณทั้งหมดมาจาก AI ไม่ใช่คำแนะนำการลงทุน ควรดูสถิติให้นานพอก่อนจะเอาไปใช้กับเงินจริง

## บอทโพสต์อะไรบ้าง

- ข่าวที่สำคัญ ชั่วโมงละไม่เกิน 3 ข่าว แต่ละข่าวบอกชื่อหุ้น ทิศทาง ระยะเวลาที่คาดว่าผลจะเกิด (1 ถึง 20 วันทำการ) ความมั่นใจ 1 ถึง 5 ดาว และเหตุผลสั้น ๆ
- ผลของสัญญาณที่ครบกำหนด ว่าได้หรือเสียกี่เปอร์เซ็นต์ และตลาดช่วงเดียวกันเป็นยังไง
- สรุปสถิติทุกวันจันทร์ 08:07 น.
- ถ้ามีสัญญาณ 5 ดาว จะแท็ก @everyone ให้รู้

นอกจากนี้บอทจะสร้างหน้าเว็บสรุปผลไว้ในโฟลเดอร์ `docs` อัปเดตทุกชั่วโมง

## ไฟล์ในโปรเจกต์

- `run.py` ตัวบอท
- `feeds.py` รายชื่อเว็บข่าว เพิ่มหรือลบได้
- `requirements.txt` ไลบรารีที่ต้องใช้
- `.github/workflows/newsbot.yml` ตั้งค่าให้ GitHub รันบอท
- `newsbot.db` ที่เก็บข้อมูลของบอท สร้างเองตอนรันครั้งแรก ห้ามลบ ไม่อย่างนั้นสถิติหายหมด
- `docs/index.html` หน้าเว็บสรุปผล สร้างเองเหมือนกัน

## วิธีติดตั้ง

### 1. สร้าง Webhook ใน Discord

ไปที่ช่องที่อยากให้บอทโพสต์ กด Edit Channel แล้วไปที่ Integrations > Webhooks > New Webhook ตั้งชื่อตามใจ แล้วกด Copy Webhook URL เก็บไว้

ลิงก์นี้ห้ามให้ใคร ใครได้ไปก็โพสต์ลงช่องเราได้

### 2. ขอ API key ของ Gemini

เข้า aistudio.google.com ล็อกอินด้วยบัญชี Google แล้วกด Get API key > Create API key ได้คีย์ที่ขึ้นต้นด้วย `AIza` มา ใช้ฟรี ไม่ต้องผูกบัตร

### 3. สร้าง repo บน GitHub

สร้าง repo ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดขึ้นไป

ไฟล์ `newsbot.yml` ต้องอยู่ในโฟลเดอร์ `.github/workflows` เท่านั้น ถ้าลากขึ้นไปแล้วโฟลเดอร์ไม่ติดไปด้วย ให้กด Add file > Create new file พิมพ์ชื่อ `.github/workflows/newsbot.yml` แล้วก๊อปเนื้อหาไปวางเอง

แนะนำให้ตั้ง repo เป็น Public เพราะจะรันได้ไม่จำกัด ถ้าเป็น Private จะได้เวลารันฟรีประมาณ 2,000 นาทีต่อเดือน ซึ่งอาจไม่พอ คีย์ที่ใส่ใน Secrets ยังเป็นความลับอยู่ดีถึงจะเป็น Public แต่คนอื่นจะเห็นโค้ดกับประวัติสัญญาณ

### 4. ใส่คีย์

ไปที่ Settings > Secrets and variables > Actions แท็บ Secrets แล้วเพิ่มสองตัวนี้

| Name | ค่า |
|---|---|
| `DISCORD_WEBHOOK_URL` | ลิงก์ Webhook จากข้อ 1 |
| `GEMINI_API_KEY` | คีย์จากข้อ 2 |

### 5. ให้สิทธิ์บอทบันทึกข้อมูล

Settings > Actions > General เลื่อนลงไปที่ Workflow permissions เลือก Read and write permissions แล้วกด Save

### 6. ลองรัน

ไปที่แท็บ Actions เลือก NewsTrader ทางซ้าย แล้วกด Run workflow รอสัก 1 ถึง 3 นาที ถ้าขึ้นเครื่องหมายถูกสีเขียวและมีข่าวโผล่ใน Discord ก็ใช้ได้แล้ว

ถ้าขึ้นกากบาทสีแดง กดเข้าไปดูที่ขั้น Run bot จะมีบอกว่าพังเพราะอะไร

## ทำให้รันตรงเวลา

ใน `newsbot.yml` ตั้งให้ GitHub รันเองทุกชั่วโมงไว้แล้ว แต่ในทางปฏิบัติ GitHub ชอบข้ามรอบ บางคืนรันแค่รอบเดียว เลยต้องใช้ cron-job.org (ฟรี) มากดรันแทน

**สร้าง token ก่อน**

GitHub > รูปโปรไฟล์ > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token

- Repository access เลือก Only select repositories แล้วเลือก repo ของบอท
- Permissions เลือก Actions เป็น Read and write

กด Generate แล้วก๊อป token เก็บไว้ (ขึ้นต้นด้วย `github_pat_`) จะเห็นแค่ครั้งเดียว

**ตั้งใน cron-job.org**

สมัครแล้วกด Create cronjob

- URL: `https://api.github.com/repos/ชื่อผู้ใช้/ชื่อrepo/actions/workflows/newsbot.yml/dispatches`
- Schedule: เลือก Custom แล้วใส่ `45 * * * *` (นาทีที่ 45 ของทุกชั่วโมง)
- แท็บ Advanced ตั้ง Request method เป็น POST แล้วเพิ่ม Headers สามตัว

| Key | Value |
|---|---|
| `Authorization` | `Bearer ` ตามด้วย token |
| `Accept` | `application/vnd.github+json` |
| `Content-Type` | `application/json` |

- Request body: `{"ref":"main"}`

กด Test run ถ้าได้ 204 แปลว่าใช้ได้ แล้วกด Create

สรุปวันจันทร์ก็ควรตั้งแบบเดียวกันอีกอันหนึ่ง ใช้ Schedule `7 8 * * 1` และ Request body เป็น `{"ref":"main","inputs":{"mode":"stats"}}`

ไม่ต้องห่วงว่าจะโพสต์ซ้ำ บอทจำข่าวที่ส่งไปแล้ว ถึง GitHub กับ cron-job.org จะรันพร้อมกันก็ไม่โพสต์ซ้ำ

## เปิดหน้าเว็บสรุปผล

Settings > Pages ตั้ง Source เป็น Deploy from a branch เลือก branch `main` โฟลเดอร์ `/docs` แล้วกด Save

ถ้ายังไม่มีโฟลเดอร์ `/docs` ให้เลือก รอให้บอทรันสักรอบก่อน แล้วค่อยกลับมาตั้ง

หน้าเว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/` ใครมีลิงก์ก็เปิดดูได้

## ปรับแต่ง

ตั้งได้ที่ Settings > Secrets and variables > Actions แท็บ Variables ไม่ตั้งก็ได้ บอทจะใช้ค่าเริ่มต้น

| Name | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `MODEL` | `gemini-3.5-flash,gemini-flash-latest,gemini-3.1-flash-lite` | รุ่น Gemini ที่ใช้ ใส่ได้หลายตัว ถ้าตัวแรกใช้ไม่ได้จะลองตัวถัดไป |
| `MARKETS` | `US,TH` | ตลาดที่ให้ออกสัญญาณ เลือกได้จาก US, TH, JP, HK, UK, EU, KR, SG, IN, TW, CN, AU |
| `MAX_EVENTS` | `3` | จำนวนข่าวสูงสุดต่อชั่วโมง |
| `LANGUAGE` | `Thai` | ภาษาที่ใช้เขียนสรุปข่าว |
| `BOT_NAME` | `News Trader` | ชื่อที่แสดงใน Discord |
| `ALERT_MIN_CONF` | `5` | ความมั่นใจกี่ดาวขึ้นไปถึงจะแท็ก ใส่ `6` ถ้าไม่อยากให้แท็กเลย |
| `ALERT_MENTION` | `@everyone` | ใช้แท็กใคร เปลี่ยนเป็น `@here` หรือแท็ก role ด้วย `<@&ID ของ role>` ก็ได้ |
| `PENDING_MAX_DAYS` | `7` | สัญญาณที่รอราคานานเกินกี่วันให้ยกเลิกทิ้ง |

ถ้าอยากใช้ AI เจ้าอื่น ตั้ง `PROVIDER` เป็น `groq` (ฟรี) หรือ `claude` (เสียเงิน) แล้วเพิ่ม Secret `GROQ_API_KEY` หรือ `ANTHROPIC_API_KEY` ตามเจ้าที่ใช้

## บอทคิดยังไง

- หุ้นที่มีสัญญาณค้างอยู่ จะไม่ได้สัญญาณใหม่จนกว่าตัวเดิมจะครบกำหนด กันไม่ให้หุ้นตัวเดียวโผล่ซ้ำ ๆ หรือทายขึ้นทีลงที
- ข่าวที่รายงานไปแล้วในสองวันล่าสุดจะไม่ถูกหยิบมาซ้ำ ถึงจะมาจากสำนักข่าวอื่นก็ตาม
- ถ้าตอนโพสต์ตลาดปิดอยู่ บอทจะรอราคาตอนตลาดเปิดรอบถัดไปก่อนค่อยเริ่มนับ จะได้วัดผลได้ยุติธรรม
- ตอนครบกำหนด บอทจะเทียบกับ SPY สำหรับหุ้นอเมริกา และดัชนี SET สำหรับหุ้นไทย ช่อง "ชนะตลาด" คือบอททำได้ดีกว่าซื้อดัชนีเฉย ๆ กี่เปอร์เซ็นต์
- สำหรับ SHORT ตัวเลขเป็นบวกแปลว่าหุ้นลงจริงตามที่ทาย

## อ่านสถิติยังไง

ควรรอให้มีสัญญาณที่ครบกำหนดอย่างน้อยร้อยตัว ซึ่งน่าจะใช้เวลาสองถึงสามเดือน ก่อนหน้านั้นตัวเลขยังขึ้นลงตามดวงเยอะ

ตัวเลขที่ควรดูมากที่สุดคือ "ชนะตลาดเฉลี่ย" ถ้าเป็นบวกต่อเนื่อง แปลว่าบอทเลือกหุ้นได้ดีกว่าตลาดจริง แต่ถ้าแค่อัตราทายถูกสูงแต่ชนะตลาดติดลบ แปลว่าบอทแค่ตามตลาดไปเฉย ๆ

ดูตารางแยกตามความมั่นใจด้วย ถ้าดาวมากยิ่งแม่นกว่าดาวน้อย แปลว่าเชื่อระดับความมั่นใจของบอทได้ อาจเลือกตามแค่สัญญาณ 4 ถึง 5 ดาว

สถิตินับเฉพาะสัญญาณหลังอัปเดตเวอร์ชัน 2 สัญญาณรุ่นแรกยังปิดและโพสต์ผลตามปกติ แต่ไม่นับในสถิติ เพราะตอนนั้นยังไม่มีระบบกันซ้ำ

## เจอปัญหา

**ขั้น Save state พัง หรือขึ้น Permission denied**
ยังไม่ได้ทำข้อ 5 ในวิธีติดตั้ง

**ขึ้น model failed หรือ Error code 404**
บัญชีเราใช้รุ่นนั้นไม่ได้ ดูในบรรทัด `available models` ใน log ว่ามีรุ่นอะไรบ้าง แล้วตั้ง `MODEL` ใหม่

**ขึ้น Error code 503**
เซิร์ฟเวอร์ Gemini รุ่นนั้นคนใช้เยอะ บอทจะลองรุ่นถัดไปเอง ถ้าเจอบ่อยให้สลับลำดับใน `MODEL`

**รันนานผิดปกติ**
ส่วนใหญ่เป็นเพราะรอ Gemini ตอบ บอทตั้งเวลาไว้ไม่ให้เกิน 7 นาทีอยู่แล้ว ถ้าเกินก็หยุดเอง ข้อมูลไม่หาย

**ไม่มีข่าวโพสต์เลยบางชั่วโมง**
ปกติ แปลว่ารอบนั้น AI ไม่เห็นข่าวที่สำคัญพอ ดูใน log บรรทัด `analyzed with ... 0 events`

**สัญญาณขึ้นว่ารอราคานาน**
หุ้นอเมริกาจะได้ราคาตอนตลาดเปิด ประมาณสามทุ่มครึ่งตามเวลาไทย ถ้าค้างเกิน 7 วันบอทจะยกเลิกเอง

**อยากหยุดบอท**
Actions > NewsTrader > ปุ่มสามจุด > Disable workflow แล้วไปปิด cronjob ใน cron-job.org ด้วย

## รันบนเครื่องตัวเอง

ถ้าอยากลองบนคอม ต้องมี Python 3.10 ขึ้นไป

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

บน Mac หรือ Linux ใช้ `source venv/bin/activate` แทนบรรทัดที่สอง

จากนั้นสร้างไฟล์ `.env` ใส่ค่าแบบนี้

```
DISCORD_WEBHOOK_URL=ลิงก์ webhook
GEMINI_API_KEY=คีย์ gemini
```

แล้วรัน `python run.py` บอทจะทำงานหนึ่งรอบแล้วจบ

ไฟล์ `.env` ห้ามอัปโหลดขึ้น GitHub เด็ดขาด
